# Styled Basic HTML Website

Bu klasör `CV-KOD-2` projesinin stil uygulanmış (CSS) versiyonunu içerir.

İçerik:
- `index.html`, `projeler.html`, `makaleler.html`, `iletisim.html`
- `css/style.css` — responsive düzen, CSS değişkenleri, Google Fonts ve karanlık mod desteği

Yerel olarak çalıştırmak için:

```powershell
cd C:\Users\turut\CV-KOD-2\styled
start index.html
```

Barındırma için öneriler:
- GitHub Pages veya Cloudflare Pages ile ücretsiz yayınlayabilirsiniz.

Bonus öneriler:
- İsterseniz `styles.css` içinde renk değişkenlerini değiştirip karanlık mod anahtar desteği ekleyebilirim.
